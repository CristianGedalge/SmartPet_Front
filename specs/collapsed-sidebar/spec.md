# Sidebar contraíble

## Objetivo
Permitir contraer el sidebar de ADMIN y ENCARGADO en escritorio para ampliar el contenido.

## Requisitos y aceptación
- Botón accesible para contraer/expandir; conservar logo, iconos y avatar en modo compacto.
- Navegación activa visible, nombres de enlaces disponibles con hover y foco.
- El contenido aprovecha el espacio liberado, sin superposición.
- Conservar perfil y cierre de sesión en el menú del avatar.
- Recordar la preferencia tras navegar o recargar; tolerar almacenamiento local no disponible.
- En móvil mantener sidebar completo como panel desplegable, independiente de la preferencia de escritorio.
- Sin cambios de rutas, API ni dependencias. Build y lint deben pasar.
